The CIA Framework

Core Framework

Data is a valuable asset. The primary goal of cybersecurity is to maintain three critical properties — collectively known as the CIA Triad — for all data, all the time.

Confidentiality

Data is not revealed

Protection against unauthorized access. Only those with proper permission should ever be able to read or view the data.

Think of it as a locked diary — only the owner (or those granted access) can read it.

REAL-WORLD BREACH Edward Snowden's 2013 leak of classified NSA government data is a landmark example of a Confidentiality breach.

Integrity

Data is intact - not modified or corrupted

Protection against unauthorized modification. Data must remain accurate and trustworthy from the moment it is created until it is accessed.

If someone changes your grade in the grade book without permission, that's an Integrity breach.

REAL-WORLD BREACH The Stuxnet worm secretly altered code on Iranian centrifuge machines, causing them to spin too fast and physically break — a classic Integrity attack.

Availability

Data is accessible to allowed users

Protection against denial of service. Authorized users must be able to access data and systems whenever they legitimately need them.

A website that is always down, or an account that stays locked, fails the Availability test.

REAL-WORLD BREACH The Mirai Botnet used 145,000+ infected cameras and devices to flood security journalist Brian Krebs' website with traffic, crashing it for 4 days — a textbook DDoS / Availability breach.
Security Formula: Protection = Prevention + (Detection + Response). Every cybersecurity technique fits into at least one of these three elements, and every element maps back to the CIA Triad.

Three States of Data

Where Data Exists

Data changes form depending on how it is being used. Cybersecurity professionals must protect data in every state to prevent theft, modification, or destruction.

Data at Rest

Stored Information

Data at rest refers to information stored on hard drives, databases, USB drives, cloud storage, or backup systems.

Encryption is commonly used to protect stored data from unauthorized access.

Data in Transit

Moving Information

Data in transit is information actively traveling across a network, such as emails, messages, or online banking traffic.

Secure protocols like HTTPS and VPNs help protect data while it moves between systems.

Data in Use

Active Information

Data in use is actively being accessed, processed, or modified by a user or application.

Because the data is open and active, this state is often the hardest to secure.

Authentication (AAA)

Identity & Access Control

Authentication systems use the AAA model — Authentication, Authorization, and Accounting — to verify identity, control access, and track activity.

Authentication

Who are you?

Authentication verifies a user's identity before access is granted to a system or resource.

Common examples include passwords, PINs, biometrics, and security tokens.

Authorization

What can you access?

Authorization determines what resources a verified user is allowed to access.

An employee may be allowed to view files but not edit or delete them.

Accounting

What actions occurred?

Accounting tracks and records user activity within systems and networks.

Security logs help investigators detect suspicious behavior and respond to incidents.

Passwords

First Line of Defense

Passwords remain one of the most common authentication methods. Strong password habits significantly reduce the risk of unauthorized access.

Strong Passwords

Strong passwords use a mix of uppercase letters, lowercase letters, numbers, and symbols.

Longer passwords are generally more secure and harder to crack.

Password Mistakes

Reusing passwords across multiple websites creates major security risks.

Attackers often use leaked passwords from one breach to access other accounts.

Password Managers

Password managers securely store and generate unique passwords for every account.

This allows users to maintain stronger security without needing to memorize dozens of passwords.

Hashing

Protecting Stored Passwords

Hashing converts data into a fixed-length value called a hash. Modern systems store password hashes instead of actual passwords to improve security.

What is a Hash?

A hash is a unique output generated from input data using a mathematical algorithm.

Even a tiny change in the original data creates a completely different hash.

One-Way Function

Hashing is designed to work in one direction only.

You can create a hash from a password, but you should not be able to reverse the hash back into the original password.

Salting

Salting adds random data to passwords before hashing them.

This prevents attackers from using precomputed rainbow tables to crack passwords quickly.

Authentication Methods

Ways to Verify Identity

Authentication methods rely on different factors to verify a user's identity. Many secure systems combine multiple methods for stronger protection.

Something You Know

Knowledge-based authentication includes passwords, PINs, and security questions.

This is the most common authentication factor used today.

Something You Have

Possession-based authentication includes smartphones, smart cards, and security tokens.

Multi-factor authentication often sends a verification code to a trusted device.

Something You Are

Biometric authentication uses fingerprints, facial recognition, voice recognition, or retina scans.

Biometrics are convenient because they are difficult to copy or steal.
